# Health Calculator - BMI & Body Analysis 🩺📊
Aplikasi Flutter untuk menghitung dan menganalisis status berat badan (BMI) berdasarkan tinggi badan, berat badan, usia, dan jenis kelamin. Dilengkapi dengan UI/UX modern dan rekomendasi kesehatan personal.

1. Nama Aplikasi
Health Calculator - BMI & Body Analysis

2. Deskripsi Singkat
Health Calculator adalah aplikasi cerdas untuk menghitung Body Mass Index (BMI) dan menganalisis status berat badan ideal. Aplikasi ini memberikan rekomendasi kesehatan yang dipersonalisasi berdasarkan profil pengguna dengan antarmuka yang intuitif dan desain yang menarik.

3. Fitur Utama
🎯 Kalkulasi BMI Akurat
Perhitungan BMI berdasarkan tinggi, berat, usia, dan jenis kelamin

Analisis berbeda untuk dewasa dan anak/remaja

Kategori lengkap: Underweight, Normal, Overweight, Obese

👤 Profil Personalisasi
Pemilihan jenis kelamin (Pria/Wanita)

Pengaturan tinggi badan dengan slider interaktif

Pengaturan berat badan dengan kontrol presisi

Penyesuaian usia untuk analisis yang tepat

📊 Analisis Mendalam
Status BMI dengan warna indikator

Deskripsi kondisi kesehatan

Tips kesehatan personal

5. Cara Menjalankan
Prasyarat
Flutter SDK ≥ 3.0.0

Dart SDK ≥ 3.0.0

IDE (VS Code / Android Studio)

Emulator atau perangkat fisik

Langkah Instalasi
Clone Repository

bash
git clone https://github.com/akim201104-creator/health-calculator.git
cd health-calculator
Install Dependencies

bash
flutter pub get
Run Aplikasi

bash
# Untuk web
flutter run -d chrome

# Untuk Android
flutter run

# Untuk build release
flutter build apk --release
